# Create Armory snapshot

Imported from the user's local Create-Armory working tree, version 0.6.0-dev for Minecraft 1.20.1, including the working-tree bolt-action sniper. The mod metadata identifies the author as **dcchill** and declares **Academic Free License v3.0**. The upstream declaration is preserved in `provenance/mods.toml.txt`.

The imported models, animations, textures, sound recordings, and gameplay source retain their upstream provenance. `manifest.json` records SHA-256 hashes of the source files. `provenance/` contains the corresponding Java gameplay source as text for audits. See the [Academic Free License 3.0 text](https://opensource.org/license/afl-3-0) for the declared license terms.

The Godot adaptation and original block armor meshes are maintained in Last Haul. Minecraft/Forge/Create/GeckoLib binaries and Minecraft texture or sound files are not bundled. `ArmoryAudio` synthesizes original substitutes for Minecraft's explosion, throw, and mounted-fire sound events. Attachment texture references that point to Minecraft use original solid materials.

The functional vest equipment belongs to Last Haul and uses original block-style meshes; no vanilla Minecraft armor items are included. Maska assets exist in the source, but no functional Maska item or protective stats are registered there; the adaptation exposes them as cosmetic equipment and animation previews.
