Placeholder meshes use Godot primitives serialized in scenes. No third-party assets or asset licenses are required.

The raid robot is an original procedural block model in `scripts/player/robot_body.gd`; no supplied Minecraft robot asset was found. Its joint pivots animate idle, walking, landing, damage, reboot, and shutdown. The sensor head and hanging arms cast shadows without obstructing the first-person weapon hands. Existing hand geometry and poses are retained with mechanical colors.
